# cang-knowledge-base — 藏（个人知识库）

## 是什么

落地 R-v1.0-CK-4：用户把打动自己的句子/顿悟收进「藏」，AI 自动串成思想地图（主题聚类），迷茫时按主题调出自己认下的道理。

四件事：

1. **三处一键收藏 + 手动**：镜子回答、导师回应、人文导师回应各加「收进藏里」入口；藏页可手动写一条（顿悟随手记）
2. **收藏时 LLM 增量打标**：经 `MentorService` 新场景 `cang_tag`，从「该用户已有主题 + 可新建」选 1~2 个主题；打标失败不阻塞收藏（条目落「未归组」）
3. **思想地图浏览**：藏页按主题分组展示（主题 + 条数 + 条目），「未归组」在末尾；不主动推送
4. **落库与删除**：`cang_items` + `cang_themes` + 关联表（迁移 0004）；条目可删除（`DELETE /api/cang/items/:id`）

## 为什么

- 「藏」是导师记忆的另一半：镜子是用户的表达，藏是用户认下的道理——PRD 故事里李婷翻的就是它
- 主题打标选「收藏时增量」而非批处理：收藏当下归组，地图永远是最新的；且经 MentorService 网关，不新开散装出口
- 打标失败降级为「未归组」而非 503：收藏是主行动，打标是增强——沿用 renwen-mentors 提升的失败语义原则（有主流程可让路才允许缺省）

## 不做（Out of Scope）

- 主动调出（迷茫时推一句、与 renwen 召唤联动）→ 后续版本
- 收藏附注「为什么打动我」→ 后续版本
- 条目编辑、主题改名/合并、导出（数据主权在 account 模块统一做）
- 向量语义聚类（pgvector 已装但 V1 用 LLM 打标即可解释、够用）

## 影响面

- **数据模型**：新表 `cang_items` / `cang_themes` / `cang_item_themes`（迁移 0004，纯新增）
- **跨模块**：新 `cang` 模块；`MentorService` 加 `cang_tag` 场景；中间件加 `cang/{*splat}`
- **前端**：镜子页/召唤页加收藏入口、新藏页（**含 UI Check**）
