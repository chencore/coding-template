# renwen-mentors — 人文导师团

## 是什么

落地 R-v1.0-CK-3：用户迷茫时能召唤「人文导师团」——苏格拉底、马可·奥勒留（斯多葛）、王阳明、曾国藩四位历史人物，以其视角回应用户当下的困惑，**并标注真实出处**（「你不孤独，人类都走过」）。

四件事：

1. **预置出处库**：四位人物 × 各 3-4 条真实原典条目（原文+篇名），内容在代码常量里版本化；LLM 回应必须基于注入的出处条目生成，标注用库里的篇名——**从机制上杜绝编造引文**
2. **召唤接口**：`POST /api/renwen/summon`（可选写一句当下困惑，可选人物或「让导师代选」），经 `MentorService` 新场景 `renwen_reply` 发出（记忆注入，人物视角主导）；每日上限 3 次
3. **落库可回看**：`renwen_sessions` 表（迁移 0003）；`GET /api/renwen/sessions` 拉取过往召唤
4. **前端**：镜子页加「迷茫时，请前人聊聊 →」入口 → 召唤页（困惑输入 + 人物选择 + 回应卡 + 过往列表）

## 为什么

- PRD 框架：「导师是你的引路人，历史是导师的智库」——导师团是导师人格的延伸，不是另一个散装 AI；所以走 MentorService 收口，记忆照注
- 「标注出处」是这功能的灵魂也是最大的幻觉风险点；预置出处库把 LLM 的自由度关进笼子

## 不做（Out of Scope）

- 导师团内容进导师记忆/周报的「历史共鸣」→ weekly-report 变更消费 `renwen_sessions`
- 更多人物、用户自选人物扩展、出处库的 CMS 化管理
- 语音朗读、分享卡片

## 影响面

- **数据模型**：新表 `renwen_sessions`（迁移 0003，纯新增）
- **跨模块**：新 `renwen` 模块；`MentorService` 加一个场景；中间件加 `renwen/{*splat}`
- **前端**：镜子页加入口、新召唤页（**含 UI Check**）
