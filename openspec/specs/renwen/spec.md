# Spec: Renwen Mentors（人文导师团）

**规格风格**：场景式（Scenario-based）——每条规格描述一个可验证的业务场景。

---

## 人物与出处库

### 场景 1：人物列表
- **动作**：`GET /api/renwen/figures`，头 `X-Device-Id`
- **预期**：返回 200，四位人物（苏格拉底 / 马可·奥勒留 / 王阳明 / 曾国藩），各含 id、名字、称号、风格提示；不含出处原文

### 场景 2：出处库完整性
- **前置**：`renwen/canon.ts`
- **预期**：每位人物 ≥3 条出处条目，id 全局唯一，每条含真实篇名与原文（测试断言）

---

## 召唤

### 场景 3：指定人物召唤
- **前置**：LLM 正常；用户当日未召唤过
- **动作**：`POST /api/renwen/summon`，`{ "figureId": "wangyangming", "confusion": "想辞职又怕选错。" }`
- **预期**：返回 201；`figure.id=wangyangming`；`response` 为王阳明视角的一段回应（≤200 字）；`source.title` 为预置篇名（如《传习录》）；`remainingToday=2`；落库 `renwen_sessions`

### 场景 4：导师代选 + 留空困惑
- **动作**：`POST` body 为空对象
- **预期**：201，人物按轮转确定；LLM 的 user prompt 含用户近 14 天镜子记忆（有历史时）；`remainingToday` 递减

### 场景 5：出处轮转不重复
- **前置**：同一用户连续两天对同一人物召唤（跨日不受上限影响）
- **预期**：两次的 `source.title` 不同（按累计召唤数轮转）

### 场景 6：每日上限
- **前置**：当日已召唤 3 次
- **动作**：第 4 次 `POST`
- **预期**：返回 429 `daily_limit_reached`；**不调用 LLM**、不落库

### 场景 7：LLM 失败——显式 503
- **前置**：LLM 不可达 / 密钥未配置 / 输出超 200 字
- **动作**：`POST` 召唤
- **预期**：返回 503 `renwen_unavailable`；不落库；warn 日志含失败类别、不含用户内容

### 场景 8：参数非法
- **动作**：`figureId` 为枚举外值；`confusion` 超 200 字
- **预期**：分别返回 400 `invalid_figure` / `confusion_too_long`；不调 LLM

### 场景 9：缺少设备 ID 头
- **动作**：不带 `X-Device-Id` 请求任一 `/api/renwen/*`
- **预期**：400 `missing_device_id`

---

## 历史回看

### 场景 10：过往召唤列表
- **前置**：用户有 ≥2 次召唤记录
- **动作**：`GET /api/renwen/sessions`
- **预期**：200，按时间倒序，每条含人物、回应、出处篇名、时间；最多 20 条

---

## 前端

### 场景 11：镜子页入口
- **动作**：查看镜子页（回答前后皆可）
- **预期**：hint 下方可见「迷茫时，请前人聊聊 →」入口，点击进召唤页

### 场景 12：召唤流程
- **动作**：召唤页写一句困惑，选「王阳明」，点「请他聊聊」
- **预期**：loading 后展示回应卡：meta 行「默 请来了 王阳明」+ 回应正文 + 出处篇名；剩余次数可见

### 场景 13：上限与失败提示
- **前置**：当日已达上限 / 后端不可达
- **动作**：点召唤
- **预期**：分别提示「今天已请过三次了，明天再来。」/ 可重试的不可达提示；已填困惑不丢

### 场景 14：过往列表展示
- **前置**：有历史召唤
- **动作**：打开召唤页
- **预期**：下方列表展示过往召唤（人物、日期、回应节选、出处）
