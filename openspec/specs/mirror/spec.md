# Spec: Mirror Moment（镜子时刻）

**规格风格**：场景式（Scenario-based）——每条规格描述一个可验证的业务场景。

---

## 设备标识与用户懒创建

### 场景 1：新设备首次访问
- **前置**：设备 ID `dev-abc` 从未出现
- **动作**：`GET /api/mirror/today`，头 `X-Device-Id: dev-abc`
- **预期**：`users` 表自动插入一条 `device_id='dev-abc'` 记录；正常返回当日问题

### 场景 2：缺少设备 ID 头
- **动作**：不带 `X-Device-Id` 请求任一 `/api/mirror/*`
- **预期**：返回 400，错误消息 `missing_device_id`；**不创建用户**

---

## 今日问题

### 场景 3：无历史回答的新用户——问题库首问
- **前置**：用户无任何回答记录
- **动作**：`GET /api/mirror/today`
- **预期**：返回 200，`question` 来自内置问题库，`questionSource="bank"`；不调用 LLM

### 场景 4：有历史回答——LLM 个性化生成
- **前置**：用户近 7 天有 ≥1 条回答（如多次提到「想给妈妈打电话」）
- **动作**：`GET /api/mirror/today`
- **预期**：返回 200，`question` 为 LLM 生成的一句问句（≤40 字），`questionSource="llm"`；问题落库，当天重复 GET 返回同一问题且不再调 LLM

### 场景 5：LLM 失败——问题库兜底，用户无感
- **前置**：LLM 端点不可达（或密钥未配置 / 输出超 40 字 / 输出非问句）
- **动作**：`GET /api/mirror/today`
- **预期**：返回 200，`questionSource="bank"`，问题来自问题库；日志记 warn（含失败类别，不含用户回答内容）

### 场景 6：当天问题幂等
- **前置**：当天问题已生成
- **动作**：再次 `GET /api/mirror/today`
- **预期**：返回同一问题，不产生新的 LLM 调用

---

## 提交回答

### 场景 7：首次提交当天回答
- **动作**：`PUT /api/mirror/today/answer`，`{ "text": "午休时楼下那只橘猫蹭了我一下。" }`
- **预期**：返回 201；`mirror_entries` 当天记录 `answer`/`answered_at` 写入；再次 `GET /today` 时 `answer` 字段可见

### 场景 8：当天重复提交——更新
- **前置**：当天已回答
- **动作**：再次 `PUT` 新内容
- **预期**：返回 200，回答内容更新，`answered_at` 刷新；条目数不增加

### 场景 9：空回答 / 超长回答
- **动作**：`text=""`（或纯空白）/ `text` 超过 2000 字符
- **预期**：分别返回 400 `empty_answer` / `answer_too_long`；不写库

---

## 声音档案

### 场景 10：按日期倒序分页
- **前置**：用户有 3 天已回答记录
- **动作**：`GET /api/mirror/entries?limit=2`
- **预期**：返回最近 2 条（含 date/question/answer），`nextBefore` 指向更早日期；用 `before=nextBefore` 再请求返回剩余 1 条且 `nextBefore=null`

### 场景 11：未回答条目不进入声音档案
- **前置**：今天的问题已生成但未回答
- **动作**：`GET /api/mirror/entries`
- **预期**：今天的条目不出现

---

## 界面（Flutter）

### 场景 12：镜子时刻页——未回答
- **前置**：后端可用，今日未回答
- **预期**：页面按原型 v2「数字文房」呈现——暖白底、墨色大字问句、导师署名行、底部输入框 + 朱砂「说完」按钮；有昨日回答时展示昨日回顾区

### 场景 13：提交后状态
- **动作**：输入回答点「说完」
- **预期**：按钮 loading 宽度稳定；成功后页面切换为「已回答」展示态（显示自己的回答 + 日期），非 AI 文案

### 场景 14：后端不可达
- **预期**：页面展示错误态与「重试」，不白屏不卡死（沿用骨架页三态处理模式）

### 场景 15：声音档案列表
- **动作**：从镜子时刻页进入声音档案
- **预期**：按日期倒序展示问题+回答；空档案展示空状态说明与引导回镜子时刻的动作；滚动到底加载更多
