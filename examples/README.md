# Examples

These examples are copy targets for agents. They are intentionally small: copy the shape, then fill in the project-specific content.

## Files

- `standard-change/tasks.md` - minimal OpenSpec task file with the required Hardness Check.
- `standard-change/design.md` - compact design shape for M/L changes.
- `standard-module/README.md` - a lightweight module contract example.

## Rule

Examples are not product truth. If an example conflicts with `spec/hardness.md`, the constitution wins.
