# Requirements

> **维护规则**：本文件是**项目整体需求**，仅在**人工明确要求**时修改。AI 不得擅自更新。

---

## 1. 项目定位

照见是一个 iOS App，为每个用户安排一位专属 AI 人生导师。导师调用哲学、算法、历史的人文智慧，引导用户日省、日课、藏——看见被算法喂养的「假我」，精进「真我」，最终实现自我价值。不追求流量，不卖注意力，只卖成长。

详细背景见 `docs/照见-PRD-v1.md`。

## 2. 目标用户

- **主要用户**：以「林晓」为画像（27 岁，互联网公司运营）——日均刷短视频 4 小时+，深夜刷手机是逃避而非娱乐，心里有「想成为的人」但与现实的自己渐行渐远
- **次要用户**：备考/求职人群、数字极简爱好者
- **不是我们的用户**：完全不认为自己有问题的人、需要硬性管控的未成年人（家长管控是另一条线）

## 3. 核心功能

### 版本 v1.0

- [ ] `[v1.0 新增]` **R-v1.0-CK-1 镜子时刻**：用户每天能回答一个个性化问题（V1 仅文字，1 分钟），回答被保存并串成「声音档案」
- [ ] `[v1.0 新增]` **R-v1.0-CK-2 AI 人生导师**：每个用户一位专属导师，有名字（默认「默」，可自定义）、有性格（温和引导型 / 苏格拉底追问型 / 同伴同行型，可切换）、有与用户共同的记忆；所有 AI 出口统一为导师人格，不做散装 AI
- [ ] `[v1.0 新增]` **R-v1.0-CK-3 人文导师团**：用户迷茫时能召唤历史人物视角回应（苏格拉底式提问、斯多葛式面对、王阳明式点拨等），并标注出处
- [ ] `[v1.0 新增]` **R-v1.0-CK-4 藏（个人知识库）**：打动自己的句子/顿悟一键收藏，AI 自动串成思想地图（发现反复出现的主题），迷茫时可调出
- [ ] `[v1.0 新增]` **R-v1.0-CK-5 首次体验**：不问权限不弹窗，先答 3 个 10 秒快问 → 60 秒内生成「此刻的你」速写（aha moment）
- [ ] `[v1.0 新增]` **R-v1.0-CK-6 今日日课**：基于镜子回答和知识库定制「小到不可能失败」的微行动，做完记录一句感受
- [ ] `[v1.0 新增]` **R-v1.0-CK-7 对账周报**：算法眼中的你（使用数据分析）vs 你表达的你（回答分析），配一句不评判的总结，附一条「历史共鸣」人物故事
- [ ] `[v1.0 新增]` **R-v1.0-CK-8 连续打卡与「不想说」**：照见天数连续打卡；「不想说」不是空按钮——「今天想缓缓」（记录不追问）/「替明天的我问一句」（AI 代问）/「换个问题」（换更轻的问题）
- [ ] `[v1.0 新增]` **R-v1.0-CK-9 拦截时刻**：打开抖音等灰名单 app 时出现 AI 拦截语「你现在是想逃避什么，还是真的想看？」，选「想逃避」直接进入镜子时刻；只打断不阻止（iOS 原生模块实现）
- [ ] `[v1.0 新增]` **R-v1.0-CK-10 订阅制 Pro**：39/月 或 198/年；免费层永远可用（镜子时刻每日一问），付费墙只拦「AI 深度理解」（日课定制 + 对账周报 + 思想地图）
- [ ] `[v1.0 新增]` **R-v1.0-CK-11 获客钩子**：「算法人格档案」测试页；「变化卡片」分享只显示可公开成就（连续照见天数、戒掉的深夜时长、本周完成日课数），不暴露任何回答内容
- [ ] `[v1.0 新增]` **R-v1.0-CK-12 数据主权**：导师的全部记忆属于用户，全部数据（声音档案/知识库/日记）可导出、可注销删除

### Future（暂不进版本）

- 时间胶囊：30 天前的你回放
- 组队互照：3-5 人小组互相看周报（可选共享）
- 企业版：员工数字健康 + 心理健康
- 语音回答（ASR/TTS）

## 4. 非功能需求

- **性能**：首次体验「此刻的你」速写须在 60 秒内生成；镜子时刻提问个性化随使用天数递增
- **合规**：符合个人信息保护法——数据可导出、可注销删除（R-v1.0-CK-12）；iOS 拦截只提示不阻止，避免审核拒绝
- **安全**：用户回答内容属敏感数据，分享功能（变化卡片）不得暴露回答内容；日志不泄露用户表达内容
- **多端**：跨端技术栈（Flutter / RN，具体选型待定），**仅 iOS 首发**；Android 后续版本再议
- **商业化底线**：无广告、无推荐流、无推送诱导（永不弹「你 3 天没来了」）

## 5. 非目标（明确不做什么）

- 不做屏幕使用时长统计面板（那是监控，不是镜子；且 iOS 沙盒读不到其他 app 时长，用拦截时刻绕开）
- 不做硬性锁机/强制禁用（对抗逻辑必败，只打断不阻止）
- 不做社交 feed / 社区（任何 feed 都是算法的变体，违背产品铁律「永远不给你 feed」）
- 不做家长管控 / 未成年人硬管控
- V1 不做语音回答（文字先行，ASR 选型见开放问题）
- 首发不做 Android

## 6. 成功标准

**MVP 验收：**
- [ ] 陌生用户 5 分钟内完成第一个「镜子时刻」回答（录像 + 时间戳）
- [ ] 拦截时刻出现时，用户能理解「逃避 / 想看」两个选项的含义

**3 个月目标：**
- [ ] 每日一问完成率 ≥ 70%
- [ ] 拦截后「选择逃避并进入镜子时刻」的比例 ≥ 30%
- [ ] 500 个付费订阅用户（Pro 39/月 或 198/年）
- [ ] 30 天留存 ≥ 40%
- [ ] 「算法人格档案」测试页分享率 ≥ 25%，测试 → 下载转化率 ≥ 10%
